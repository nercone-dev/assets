Forms

Text field・Button・Dropdown・Slider の表示例です。

Text field

テキストを入力する <input> (type が text、search、email、url、tel、password、number、日付と時刻のもの、または指定なし) と <textarea> に適用されます。クラスは必要ありません。ほかの要素には textfield クラスで同じ見た目を付けられます。

種類

状態

上のメールアドレス欄は、編集すると検証に失敗してエラー表示になります。

カスタマイズ

余白は --textfield-padding、色は --color-textfield-* で変えられます。

<input type="email" placeholder="you@example.com">
<textarea rows="4"></textarea>

Button

<button> と <input type="button">、<input type="submit">、<input type="reset"> に適用されます。クラスは必要ありません。<a> などほかの要素には button クラスを追加します。必要に応じてバリアントを1つ追加します。

リンク

Error (a)

カスタマイズ

<button>Cancel</button>
<button class="button-primary">Save</button>
<a class="button button-error" href="/delete">Delete</a>

Dropdown

<select> に適用されます。クラスは必要ありません。

<select>
    <option>One</option>
    <option>Two</option>
</select>

Slider

<input type="range"> に適用されます。クラスは必要ありません。slider.js を読み込むと、値までの部分が塗られます。

状態

カスタマイズ

<input type="range" min="0" max="100" value="30">

スクリプトから value を変えたときは、input イベントが発生しないため、window.nercone.get('slider').update(element) を呼んでください。
