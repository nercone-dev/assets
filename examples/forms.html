Forms

Text field・Button・Dropdown の表示例です。

Text field

<input> または <textarea> に textfield を追加します。

種類

状態

上のメールアドレス欄は、編集すると検証に失敗してエラー表示になります。

<input class="textfield" type="email" placeholder="you@example.com">
<textarea class="textfield" rows="4"></textarea>

Button

<button> または <a> に button を追加し、必要に応じてバリアントを1つ追加します。

バリアント

リンク

トップへ戻る 次へ

無効

Error (a)

カスタマイズ

<button class="button">Cancel</button>
<button class="button button-primary">Save</button>
<a class="button button-error" href="/delete">Delete</a>

Dropdown

<select> に dropdown を追加します。

<select class="dropdown">
    <option>One</option>
    <option>Two</option>
</select>
