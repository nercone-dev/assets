Navigation

Header と Sidebar の使用例です。どちらもページの端に固定され、このページの上部と左側にあるものがそれぞれの実例です。

Header

main.css は <header> を画面上部に固定し、背景をぼかします。main は Header の高さだけ上に余白を空けます。

Header の直接の子を <div> で分けると横に並び、最初の <div> が残りの幅を使います。2つ目以降の <div> は右端に寄ります。

<header>
    <div>
        <a href="/"><b>Site</b></a>
    </div>
    <div class="small:hide">
        <a href="/about">About</a>
        <a href="/blog">Blog</a>
    </div>
</header>

Sidebar

画面の端に固定されるナビゲーションです。<nav> に sidebar を追加し、main より前に置きます。main は Sidebar の幅だけ横にずれます。

幅が 768px 以下の画面では Sidebar は隠れ、sidebar-toggle のボタンで開くポップオーバーになります。開閉、外側のクリックや Esc で閉じる動作、フォーカスの管理はブラウザの popover 属性が行います。ウィンドウの幅を変えて確認してください。

<header>
    <div>
        <button class="sidebar-toggle" type="button" popovertarget="sidebar" aria-label="メニュー">…</button>
        <a href="/"><b>Site</b></a>
    </div>
</header>
<nav class="sidebar" id="sidebar" popover aria-label="サイト">
    <a href="/" aria-current="page">Home</a>
    <p class="sidebar-heading">Docs</p>
    <a href="/docs/install.html">Install</a>
    <a href="/docs/usage.html">Usage</a>
    <hr>
    <details>
        <summary>More</summary>
        <a href="/faq.html">FAQ</a>
    </details>
</nav>
<main>…</main>

要素

要素表示
<a>1行に1つのリンク。aria-current="page" を持つリンクは強調されます。
.sidebar-headingリンクのまとまりの見出し。
<details> と <summary>折りたためるまとまり。右端の三角は開くと上を向き、中のリンクは字下げされて左の線にぶら下がります。
<hr>区切り線。

sidebar.js

sidebar.js を読み込むと、次のことを行います。読み込まなくても Sidebar は表示され、ポップオーバーも開閉できます。

  • 表示中のページを指すリンクに aria-current="page" を付け、それ以外のリンクからは外します。そのリンクを含む <details> は開きます。
  • ポップオーバーの中のリンクを押したときと、画面が広くなったときに、ポップオーバーを閉じます。

Sidebar は header と main の外にあるため、view-transition.js によるページ遷移では置き換えられず、スクロール位置や <details> の開閉がそのまま残ります。このため、表示中のページの印は sidebar.js が付け直します。

Important

Sidebar のリンクには / から始まるパスか完全なURLを指定してください。ページ遷移で残った Sidebar の相対URLは、移動先のページを基準に解決されます。

Tip

ページごとに Sidebar の内容が違う場合は、PageTransition の regions に '#sidebar' を加えると、Sidebar もページと一緒に置き換えられます。詳しくは Effects を見てください。

カスタマイズ

幅は --sidebar-width (既定値 240px)、左右の余白は --sidebar-padding (既定値 12px) で変えられます。--sidebar-width は main のずれにも使われるため、Sidebar と main の両方に届く :root などで指定してください。

:root {
    --sidebar-width: 280px;
}

色は --color-sidebar-* で変えられます。一覧は Colors を見てください。画面が狭いときに切り替える幅を変える場合は、sidebar.css の @media と、Sidebar の media オプションを合わせて変えてください。

window.nercone.register('sidebar', new window.nercone.Sidebar({
    media: '(max-width: 1080px)'
}));
