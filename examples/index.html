Examples

コンポーネントと通常の要素の使用例

このディレクトリには、styles/ と scripts/ の使用例が入っています。どのページも同じスタイルシートとスクリプトを読み込み、Loading overlay・Header・Sidebar・Cursor を置いているため、ページ間の移動ではページ遷移のアニメーションも確認できます。

ページはリポジトリの最上位を公開した状態で開いてください (例: python3 -m http.server を実行し /examples/ を開く)。リンクと画像は / から始まるパスで書かれています。

ページ

Typography

見出し・段落・リスト・表・引用・コードなど、HTMLの通常の要素と、フォントのクラス。
Layout

Hero・Block・Layer と、レイアウト用のユーティリティクラス。
Colors

パレット・明るさ・透明度・用途ごとの色と、色のユーティリティクラス。
Navigation

Header と Sidebar。画面が狭いときの Sidebar の開閉。
Forms

Text field・Button・Dropdown・Slider と、それらの状態。
Tables

Table とそのバリアント、横スクロール。
Overlays

Popup と Toast。開閉や通知を試せます。
Loading

Progress と Spinner。値を操作して動作を確認できます。
Effects

Cursor・Loading overlay・Page transition。
Scripts

window.nercone の API、TopLayer、各スクリプトのオプション。

読み込み

必要なファイルだけを読み込んでください。colors.css はすべてのコンポーネントで必要です。

<link rel="stylesheet" href="styles/colors.css">
<link rel="stylesheet" href="styles/fonts.css">
<link rel="stylesheet" href="styles/main.css">
<link rel="stylesheet" href="styles/components/button.css">
<script src="scripts/initializer.js"></script>
<script src="scripts/progress.js" defer></script>
