Scripts

scripts/ のスクリプトに共通する仕組みと、スクリプトから使える API の一覧です。各コンポーネントの使い方は、それぞれのページを見てください。

initializer.js

ほかのスクリプトより先に、defer を付けずに読み込みます。window.nercone を作り、各スクリプトの機能 (feature) を登録・管理します。

<script src="scripts/initializer.js"></script>
<script src="scripts/toast.js" defer></script>

window.nercone

メソッド動作
register(name, feature)機能を登録し、DOM の準備ができたら init() を呼びます。同じ名前の機能があれば、先にそれを止めます。
unregister(name)機能を止め (destroy()、なければ cleanup())、登録を消します。
get(name)登録されている機能を返します。なければ null です。
cleanup()すべての機能の cleanup() を呼びます。ページ遷移で中身を入れ替える直前に呼ばれます。
reinit(doc)すべての機能の reinit(doc) を呼びます。ページ遷移で中身を入れ替えた直後に、新しいページの Document を渡して呼ばれます。
setNavigator(navigator)ページ遷移を行うオブジェクトを登録します。view-transition.js が使います。
navigate(href)登録されたナビゲーターでページを移動します。なければ通常のページ移動をします。

機能は、次のメソッドを必要なものだけ持つオブジェクトです。メソッドが例外を投げても、ほかの機能は止まりません。

window.nercone.register('clock', {
    init()       { /* ページを開いたとき */ },
    cleanup()    { /* ページ遷移で中身を入れ替える直前 */ },
    reinit(doc)  { /* ページ遷移で中身を入れ替えた直後 */ },
    destroy()    { /* unregister や、同じ名前での register */ }
});

各スクリプトのクラスも window.nercone に置かれています (window.nercone.Toast など)。オプションを変えるときは、新しいインスタンスを同じ名前で登録します。

TopLayer

モーダルの Popup などは、どの z-index よりも上の top layer に表示されます。それよりも上に表示し続けたい要素は window.nercone.topLayer に登録します。order が大きい要素ほど上になります。

window.nercone.topLayer.add(element, order);
window.nercone.topLayer.remove(element);

Toast は 0、Cursor は 1、Loading overlay は 2 で登録されています。下のボタンは Popup を開いた 1 秒後に Toast を表示します。Toast とカーソルが Popup より上に表示されます。

オプション

オプションはコンストラクタに渡します。渡さなかった項目には既定値が使われます。

Cursor

名前既定値説明
selector'#cursor'カーソルの要素。
linkSelector'a, button, …'カーソルが囲む要素。
systemSelector'.cursor-system'システムのカーソルを使う領域。
activeClass'cursor-active'カーソルが表示されている間 <html> に付くクラス。
padding6要素を囲むときの余白 (px)。
linkGap4要素の外側でも囲む距離 (px)。
textGap4文字の外側でも縦線にする距離 (px)。
layer1TopLayer での順番。

LoadingOverlay

名前既定値説明
selector'#loading-overlay'オーバーレイの要素。
easing'cubic-bezier(…)'アニメーションのイージング。
layer2TopLayer での順番。
duration.in3000ロゴを描く時間 (ms)。
duration.wait1000描き終えてから消え始めるまでの時間 (ms)。
duration.out1000消える時間 (ms)。

PageTransition

名前既定値説明
regions['header', 'main']入れ替える要素。どれかが移動先にない場合は通常のページ移動になります。
keepMeta['charset', 'viewport', 'color-scheme', 'theme-color']入れ替えない <meta> の名前。
headers{ 'X-Requested-With': 'view-transition' }ページを取得するときのリクエストヘッダー。
