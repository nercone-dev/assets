Tables

Table の表示例です。

基本

<table> に table を追加します。<thead> の見出しには背景が付きます。

コンポーネント ファイル スクリプト
Button button.css 不要
Slider slider.css slider.js
Table table.css 不要
Popup popup.css popup.js
Toast toast.css toast.js 
<table class="table">
    <thead>
        <tr><th>Name</th><th>Value</th></tr>
    </thead>
    <tbody>
        <tr><td>One</td><td>1</td></tr>
    </tbody>
</table>
