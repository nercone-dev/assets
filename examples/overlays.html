<dialog id="confirm" closedby="any" aria-labelledby="confirm-title">
    <h2 id="confirm-title">削除しますか？</h2>

幅は --popup-width (既定値 480px)、内側の余白は --popup-padding、背景のぼかしは --popup-backdrop-blur で変えられます。

カスタマイズ

--popup-width: 640px; --popup-padding: 48px; --popup-backdrop-blur: 16px

data-popup-close の値は returnValue になり、close イベントで読み取れます。<form method="dialog"> も使えます。スクリプトからは次のように操作します。

const popup = window.nercone.get('popup');
popup.open('confirm');
popup.close('confirm', 'cancel');
popup.toggle(document.getElementById('confirm'));

Toast

短い通知を画面の端に表示し、一定時間後に自動で閉じます。toast.js を読み込み、data-toast="メッセージ" を持つ要素をクリックするか、スクリプトから表示します。ポインターやフォーカスが Toast にある間は自動で閉じません。

バリアント

<button data-toast="保存しました" data-toast-variant="success">保存</button>

スクリプト

const toast = window.nercone.get('toast');
toast.show('保存しました', { variant: 'success' });
toast.show('自動で閉じない', { duration: 0 });
toast.show('閉じるボタンなし', { dismissible: false });

const element = toast.show('処理中');
toast.pause(element);   // 自動で閉じるまでの時間を止める
toast.resume(element);  // 続きから数える
toast.close(element);
toast.clear();

show() は Toast の要素を返します。message には文字列のほか、要素 (Node) も渡せます。

variant は information・success・warning・error のいずれかです。warning と error は role="alert" になり、支援技術ですぐに読み上げられます。

見た目の変更

幅は --toast-width (既定値 360px)、画面の端からの距離は --toast-offset、内側の余白は --toast-padding、色は --color-toast-* で変えられます。コンテナは <body> の直下に作られるため、:root などで指定してください。

:root {
    --toast-width:  420px;
    --toast-offset: 16px;
}

位置などの変更

オプションを変えるときは、新しいインスタンスを同じ名前で登録します。位置は top-start・top-center・top-end・bottom-start・bottom-center・bottom-end から選べます。

window.nercone.register('toast', new window.nercone.Toast({
    position: 'top-center',
    duration: 3000,
    limit:    3,
    label:    '通知',
    closeLabel: '閉じる'
}));
