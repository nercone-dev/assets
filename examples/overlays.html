Popup

data-popup-close の値は returnValue になり、close イベントで読み取れます。<form method="dialog"> も使えます。スクリプトからは次のように操作します。

const popup = window.nercone.get('popup');
popup.open('confirm');
popup.close('confirm', 'cancel');
popup.toggle(document.getElementById('confirm'));

Toast

短い通知を画面の端に表示し、一定時間後に自動で閉じます。toast.js を読み込み、data-toast="メッセージ" を持つ要素をクリックするか、スクリプトから表示します。ポインターやフォーカスが Toast にある間は自動で閉じません。

バリアント

<button class="button" data-toast="保存しました" data-toast-variant="success">保存</button>

スクリプト

const toast = window.nercone.get('toast');
toast.show('保存しました', { variant: 'success' });
toast.show('自動で閉じない', { duration: 0 });
toast.clear();

variant は information・success・warning・error のいずれかです。warning と error は role="alert" になり、支援技術ですぐに読み上げられます。

位置などの変更

オプションを変えるときは、新しいインスタンスを同じ名前で登録します。位置は top-start・top-center・top-end・bottom-start・bottom-center・bottom-end から選べます。

window.nercone.register('toast', new window.nercone.Toast({
    position: 'top-center',
    duration: 3000,
    limit:    3,
    label:    '通知',
    closeLabel: '閉じる'
}));
