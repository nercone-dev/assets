Effects

Cursor・Loading overlay・Page transition の使用例です。これらはページ全体に作用し、すべての例のページで有効です。

Cursor

<div id="cursor"></div> を置き、cursor.js を読み込むと、マウスカーソルが円に置き換わります。リンクやボタンの上では要素を囲む形に、テキストの上では縦線に変わります。すべての例のページで有効です。

リンクの上

この領域 (cursor-system) ではシステムのカーソルが使われます。

<link rel="stylesheet" href="styles/components/cursor.css">
<script src="scripts/cursor.js" defer></script>
...
<div id="cursor"></div>

押している間は少し縮みます。色は --color-cursor と --color-cursor-on-link で変えられます。マウス以外 (タッチやペン) の操作ではカーソルは表示されません。囲む要素の種類や余白は、オプションで変えられます。

window.nercone.register('cursor', new window.nercone.Cursor({
    linkSelector: 'a, button',
    padding:      8
}));
summary (既定で囲まれます)

下のボタンでカーソルのオプションを変えると、summary が囲まれなくなります。別のページに移動しても、再読み込みするまで変更は残ります。

Loading overlay

ページを直接開いたときに、ロゴを描くアニメーションの後でページを表示します。すべての例のページに置かれており、このページを開いたときに表示されたものです。

Loading overlay は header と main の外にあるため、ページ遷移では再生されません。再生が終わると要素は取り除かれます。JavaScript が無効な環境では noscript.css によって非表示になり、視差効果を減らす設定 (prefers-reduced-motion) ではロゴを描かずにフェードアウトだけをします。

<link rel="stylesheet" href="styles/components/loading-overlay.css">
<noscript><link rel="stylesheet" href="styles/noscript.css"></noscript>
<script src="scripts/loading-overlay.js" defer></script>
...
<div id="loading-overlay">
    <svg viewBox="96 256 832 512" xmlns="http://www.w3.org/2000/svg">
        <polyline points="872 572.75 152 332 152 692 512 692 872 332 872 692 684.5 692" fill="none" stroke="currentColor" stroke-width="48" stroke-miterlimit="10"/>
    </svg>
</div>

時間はオプションで変えられます。

window.nercone.register('loading-overlay', new window.nercone.LoadingOverlay({
    duration: { in: 1500, wait: 500, out: 500 }
}));

Page transition

view-transition.js を読み込むと、同じオリジンのリンクを開くときに header と main だけを入れ替え、View Transition API でアニメーションします。対応していないブラウザでは通常のページ移動になります。

Typography へ Layout へ 新しいタブで開く (遷移なし) 
<link rel="stylesheet" href="styles/components/view-transition.css">
<script src="scripts/initializer.js"></script>
<script src="scripts/view-transition.js" defer></script>

遷移では次のことを行います。

  • 移動先のページを取得し、まだ読み込んでいないスタイルシートとスクリプトを先に読み込みます。
  • <title>、<meta>、canonical、<style> を移動先のものに合わせます。
  • 入れ替えの前後に window.nercone.cleanup() と window.nercone.reinit(doc) を呼び、各機能を新しいページに合わせます。
  • 戻る・進むではスクロール位置を復元し、#id へのリンクではその要素までスクロールします。

次の場合は通常のページ移動になります: 別のオリジン、target や download を持つリンク、修飾キーを押しながらのクリック、HTML 以外の応答、移動先に入れ替える要素がない場合。

ページ内のリンク (#id) HTML 以外 (通常の移動)

入れ替える要素は regions で変えられます。ページごとに内容が違う Sidebar も入れ替える例です。

window.nercone.setNavigator(new window.nercone.PageTransition({
    regions: ['header', '#sidebar', 'main']
}));

サーバーは X-Requested-With: view-transition ヘッダーで、遷移のための取得かどうかを判断できます。アニメーションは view-transition.css で header と main に名前を付けて行っています。視差効果を減らす設定ではアニメーションしません。
