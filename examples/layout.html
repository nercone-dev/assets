Layout

Hero・Block・Layer とユーティリティクラス

Hero

main の最初の子に hero を置くと、画面幅いっぱいに広がります。背景画像は --hero-image で指定します。このページの最上部が Hero です。

相対URLはページではなく hero.css の位置を基準に解決されるため、/ から始まるパスか完全なURLを指定してください。

<div class="hero" style="--hero-image: url('/images/header/wide.webp')">
    <h1>Title</h1>
    <p>Subtitle</p>
</div>

Block

枠線で囲まれた領域です。最初の子が <b> の場合、それが見出しとして色付けされます。

バリアントなしの Block です。

Note

知っておくと役に立つ情報です。

Tip

より良く使うためのヒントです。

Important

目的を達成するために必要な情報です。

Warning

問題を避けるために注意が必要な情報です。

Caution

操作によるリスクや悪影響についての情報です。

<div class="block block-note">
    <b>Note</b>
    <p>Text</p>
</div>

Layer

背景色の付いた領域です。バリアントは Block と同じです。

バリアントなしの Layer です。

Note

知っておくと役に立つ情報です。

Tip

より良く使うためのヒントです。

Important

目的を達成するために必要な情報です。

Warning

問題を避けるために注意が必要な情報です。

Caution

操作によるリスクや悪影響についての情報です。

<div class="layer layer-tip">
    <b>Tip</b>
    <p>Text</p>
</div>

Flex

flex で子要素を横に並べ、flex:1 から flex:10 で比率を指定します。

flex:1

flex:2

flex:3

<div class="flex">
    <div class="flex:1">...</div>
    <div class="flex:2">...</div>
</div>

レスポンシブ

画面幅に応じて表示を切り替えます。ウィンドウの幅を変えて確認してください。

幅が 768px より大きいときに表示されます (small:hide)。

幅が 768px 以下のときに表示されます (hide small:show)。

枠線

border クラスで枠線を付けた要素です。
