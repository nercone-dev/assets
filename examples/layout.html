Hero・Block・Layer とユーティリティクラス

Hero

main の最初の子に hero を置くと、main の余白を越えて main の幅いっぱいに広がります。Sidebar がある場合は、Sidebar を除いた幅になります。main の外では画面幅いっぱいに広がります。背景画像は --hero-image で指定します。このページの最上部が Hero です。

相対URLはページではなく hero.css の位置を基準に解決されるため、/ から始まるパスか完全なURLを指定してください。

<div class="hero" style="--hero-image: url('/images/header/wide.webp')">
    <h1>Title</h1>
    <p>Subtitle</p>
</div>

Block

枠線で囲まれた領域です。最初の子が <b> の場合、それが見出しとして色付けされます。

バリアントなしの Block です。

Note

知っておくと役に立つ情報です。

Tip

より良く使うためのヒントです。

Important

目的を達成するために必要な情報です。

Warning

問題を避けるために注意が必要な情報です。

Caution

操作によるリスクや悪影響についての情報です。

<div class="block block-note">
    <b>Note</b>
    <p>Text</p>
</div>

Details

<details> は、見出しの帯と中身の領域に分かれた見た目になります。クラスは必要ありません。右端の三角は開くと上を向きます。

閉じた状態

中身です。

開いた状態

中身の要素は左右と上に --details-padding (既定値 16px) の余白を空けて並びます。

Text
-----END EXAMPLE-----
<details>
    <summary>Title</summary>
    <p>Text</p>
</details>

flex で子要素を横に並べ、flex:1 から flex:10 で比率を指定します。

flex:1

flex:2

flex:3

    <div class="flex:1">...</div>
    <div class="flex:2">...</div>
</div>

レスポンシブ

画面幅に応じて表示を切り替えます。hide と show は常に、small: は幅 768px 以下、medium: は 769px から 1080px、large: は 1081px 以上で適用されます。ウィンドウの幅を変えて確認してください。

small (〜768px) です。(hide small:show)

medium (769px〜1080px) です。(hide medium:show)

large (1081px〜) です。(hide large:show)

幅が 768px 以下のときは隠れます (small:hide)。

幅が 1081px 以上のときは隠れます (large:hide)。

<nav class="small:hide">…</nav>
<button class="hide small:show">…</button>

show 系のクラスは display: block にします。上の small:show などの Layer も、表示されている間は block になっています。flex などほかの display が必要な要素では、hide を使わずに *:hide の組み合わせで切り替えてください。

ユーティリティクラスの優先順位

main.css・colors.css・fonts.css の、1つの性質だけを変えるクラス (このページのクラス、fg-color-*、font-weight-* など) は !important で指定されています。このため、読み込む順番や詳細度に関係なく、コンポーネントの見た目や style 属性よりも優先されます。

block bd-color-pink bg-color-pink-opacity-10 no-padding

余白

no-padding と no-margin は、すべての方向または -top・-bottom・-left・-right の1方向の余白を 0 にします。

通常の Layer

no-padding

no-padding-left

  • 通常のリスト
  • 左に余白があります
  • no-padding-left
  • 左の余白がありません
<div class="layer no-padding">…</div>
<ul class="no-padding-left">…</ul>

はみ出し

overflow-show・overflow-hide・overflow-scroll は、要素からはみ出した内容の扱いを変えます。

overflow-show: はみ出した内容もそのまま表示されます。はみ出した内容もそのまま表示されます。

overflow-hide: はみ出した内容は隠れます。はみ出した内容は隠れます。はみ出した内容は隠れます。

overflow-scroll: はみ出した内容はスクロールで見られます。はみ出した内容はスクロールで見られます。

選択

unselectable はテキストを選択できなくします。selectable は、選択できない要素の中で再び選択できるようにします。

この文章は選択できません (unselectable)。

この文章は選択できます (selectable)。
