Colors

All colors defined in color.css. Hover a swatch to see its variable name. Click a swatch to copy its color. Use the control at the top right of each panel to choose the copied format: variable name, RGB, or hex.

Palette

Each hue has 41 steps in increments of 5: from 0 (black) to 100 (the base color), the base color is mixed with black, and from 100 to 200 (white), it is mixed with white. Refer to them as --color-{hue}-{step}.

JIS Safety Colors

--color-jis-{name} are the safety colors of JIS Z 9103:2018. JIS does not allow changing their lightness, so they have no palette, brightness, or opacity variants; use them as they are. dark-ud, light-ud, black-ud, and white-ud use them for the status and GitHub Markdown colors.

Themes

A theme sets the semantic colors for the whole page. style.css uses dark; black, light, and white are also available. dark-ud, light-ud, black-ud, and white-ud are dark, light, black, and white with the status and GitHub Markdown colors replaced by the JIS safety colors, which keep the same lightness in every variant. Choose one here to see it on this site.

auto follows the system setting: light when the system prefers a light color scheme, dark otherwise. auto-stark does the same with white and black. auto-ud and auto-stark-ud are the same two with the -ud variants.

To use one theme only, load style-{theme}.css from the release instead of style.css. It is style.css followed by styles/themes/{theme}.css.

<link rel="stylesheet" href="style-light.css">

To change the theme while the page is open, use theme.js. It adds {baseURL}{theme}.css after the other stylesheets, removes the previous theme once the new one is loaded, and sets data-theme on <html>. Clicking an element with data-theme-trigger="light" applies that theme, and data-theme-trigger="" removes it. Radio buttons and checkboxes with data-theme-trigger are checked when their theme is applied.

const theme = window.nercone.get('theme');
await theme.set('light'); // true when applied, false when the stylesheet failed to load
theme.get();              // 'light'
await theme.set(null);    // back to the colors in style.css

On load, theme.js applies the saved theme, then the one in <html data-theme="…">, then the theme option; names not in themes are ignored. The theme is saved to localStorage only when storageKey is set. The default baseURL is https://assets.nercone.dev/styles/themes/; a relative URL is resolved against the page. To change the options, register a new instance under the same name:

window.nercone.register('theme', new window.nercone.Theme({
    baseURL:    '../styles/themes/',
    storageKey: 'nercone-theme'
}));

The theme stylesheet has data-view-transition-keep, so view-transition.js keeps it when it moves to another page. Because it is loaded by a script, the page is drawn with the default colors until it is loaded; style-{theme}.css does not have this delay.

Customization

The variables are defined on :root, so they can be overridden on any element. An override applies only to that element and its descendants.

<div style="--color-button-primary-background: var(--color-pink-bright)">
    <button class="button-primary">Pink primary</button>
</div>
