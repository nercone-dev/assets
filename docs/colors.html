Colors

All colors defined in color.css. Click a swatch to copy its color. Use the control at the top right of each panel to choose the copied format: variable name, RGB, or hex.

Palette

Each hue has 21 steps from 0 (black) to 100 (brightest), in increments of 5. Refer to them as --color-{hue}-{step}.

Click to copy

Brightness

Frequently used steps have names: -dark is 45, -normal is 75, and -bright is 100. --color-{hue} is the base color of each hue.

Click to copy

Opacity

--color-{hue}-opacity-{step} is the base color of the hue mixed with transparent at the given percentage. white is also available.

Utility classes

Every color above except the component colors has classes for the text color (fg-color- / text-color-), the background color (bg-color- / background-color-), and the border color (bd-color- / border-color-).

Customization

The variables are defined on :root, so they can be overridden on any element. An override applies only to that element and its descendants.

<div style="--color-button-primary-background: var(--color-pink-bright)">
    <button class="button-primary">Pink primary</button>
</div>
