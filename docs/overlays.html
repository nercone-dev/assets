Overlays

Popup and Toast. Both are drawn above the page.

Popup

Applies to <dialog> without a class. With popup.js, an element with data-popup-open="ID" opens the popup with that ID as a modal, and an element with data-popup-close inside a popup closes it. Esc also closes it.

With closedby="any", clicking outside the popup also closes it. In browsers that do not support the attribute, popup.js does the same.

<button type="button" data-popup-open="confirm">Delete</button>

<dialog id="confirm" closedby="any" aria-labelledby="confirm-title">
    <h2 id="confirm-title">Delete this item?</h2>
    <div class="popup-actions">
        <button type="button" data-popup-close="cancel">Cancel</button>
        <button class="button-error" type="button" data-popup-close="delete">Delete</button>
    </div>
</dialog>

popup-actions lines up buttons at the end of the popup.

Return value

The value of data-popup-close becomes the returnValue of the dialog, which can be read in the close event. <form method="dialog"> also works, and the value of the submit button becomes the return value.

document.getElementById('confirm').addEventListener('close', (event) => {
    if (event.target.returnValue === 'delete') { … }
});

Script

Each method takes an ID or a <dialog> element, and returns the dialog, or null when nothing changed.

const popup = window.nercone.get('popup');
popup.open('confirm');
popup.close('confirm', 'cancel');
popup.toggle(document.getElementById('confirm'));

Customization

Change the width with --popup-width (default 480px), the padding with --popup-padding (default 24px), the backdrop blur with --popup-backdrop-blur (default 4px), and the colors with --color-popup-*.

Customized

--popup-width: 640px; --popup-padding: 48px; --popup-backdrop-blur: 16px; --color-popup-border: var(--color-information-bright)

Toast

Shows a short notification at the edge of the screen, and closes it after a while. With toast.js, click an element with data-toast="Message", or show one from a script. A toast does not close by itself while the pointer or focus is on it. Toasts stay above popups.

Variants

Set data-toast-variant to information, success, warning, or error. warning and error get role="alert", so assistive technology announces them right away.

<button type="button" data-toast="Saved" data-toast-variant="success">Save</button>

Script

Toast over a popup

The toast container is kept in the top layer, so toasts are drawn above modal popups.

 
const toast = window.nercone.get('toast');
toast.show('Saved', { variant: 'success' });
toast.show('Stays until closed', { duration: 0 });
toast.show('No close button', { dismissible: false });

const element = toast.show('Working');
toast.pause(element);   // Stop the timer
toast.resume(element);  // Continue from where it stopped
toast.close(element);
toast.clear();

show() returns the toast element. The message can be a string or a Node.

Customization

Change the width with --toast-width (default 360px), the distance from the edge of the screen with --toast-offset (default 24px), the padding with --toast-padding (default 12px 16px), and the colors with --color-toast-*. The container is created directly under <body>, so set them on :root or body.

:root {
    --toast-width:  420px;
    --toast-offset: 16px;
}

To change the options, register a new instance under the same name. position is one of top-start, top-center, top-end, bottom-start, bottom-center, and bottom-end (default).

window.nercone.register('toast', new window.nercone.Toast({
    position:   'top-center',
    duration:   3000,
    limit:      3,
    label:      'Notifications',
    closeLabel: 'Close'
}));
