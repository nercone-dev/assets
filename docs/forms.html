Forms

Text field, Button, Dropdown, Slider, and Segmented control.

Text field

Applies without a class to <textarea> and to <input> whose type is text, search, email, url, tel, password, number, a date or time type, or not set. Other elements can get the same look with the textfield class.

Types

States

The second field fails validation and shows the error state after you edit it (:user-invalid).

Customization

Change the padding with --textfield-padding (default 8px 12px) and the colors with --color-textfield-*.

<input type="email" placeholder="you@example.com">
<textarea rows="4"></textarea>

Button

Applies without a class to <button>, <input type="button">, <input type="submit">, and <input type="reset">. Add the button class to other elements, such as <a>. Add one variant class if needed.

Disabled

Use the disabled attribute, or aria-disabled="true" on elements without it.

Error (a)

Customization

Change the padding with --button-padding (default 8px 16px) and the colors with --color-button-*.

<button type="button">Cancel</button>
<button class="button-primary" type="submit">Save</button>
<a class="button button-error" href="/delete">Delete</a>

Dropdown

Applies to <select> without a class. Other elements can get the same look with the dropdown class.

With multiple or a size greater than 1, the arrow is not drawn.

<select>
    <option>One</option>
    <option>Two</option>
</select>

Slider

Applies to <input type="range"> without a class. Other elements can get the same look with the slider class. slider.js fills the track up to the current value.

States

Customization

Change the size with --slider-thickness (default 4px) and --slider-thumb-size (default 16px), and the colors with --color-slider-*.

<input type="range" min="0" max="100" value="30">
Note

Setting the value property from a script fires no input event, so call window.nercone.get('slider').update(element) afterwards.

Segmented control

A set of mutually exclusive options. Put a radio button and a <span> in each <label>. The radio button stays focusable and readable by assistive technology, while the <span> is drawn.

Change the padding of each option with --segmented-control-padding (default 4px 12px).

<div class="segmented-control" role="radiogroup" aria-label="View">
    <label><input type="radio" name="view" value="list" checked><span>List</span></label>
    <label><input type="radio" name="view" value="grid"><span>Grid</span></label>
</div>
